# 🟩 W WASEELA

**WASEELA** helps skilled workers create a clear professional profile and helps households find local workers for everyday home services.

## Pages

- **Home** — introduces the WASEELA idea and its main services.
- **Find Worker** — shows workers for AC repair, electrical work and plumbing.
- **Create Profile** — lets a worker enter their work details and create a profile or QR card.

## Built with

- HTML5
- CSS3
- Flexbox and Grid

Run `home.html` with Live Server to view the website.
